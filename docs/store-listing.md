## Detailed Description

**Swift Translator** is the next generation of translation tools. Instead of sending everything you read to external servers, it leverages Chrome's cutting-edge Built-in AI Translation API to process text entirely locally on your device. 

Highlight any text, in almost any language, and get a lightning-fast translation floating right next to your cursor.

### ✨ Key Features
- **Lightning Fast Translations**: Because it runs locally, you get instant results with zero network latency.
- **100% Private & Secure**: What you read stays on your computer. Absolutely zero text or browsing data is ever transmitted to the cloud.
- **Smart Language Detection**: Swift Translator automatically detects the source language of the highlighted text for frictionless reading.
- **Beautiful Glassmorphic UI**: Experience a premium, native-feeling translation box that you can drag and drop anywhere on the page.
- **Dynamic Themes**: Fully supports Light Mode, Dark Mode, and a "Dynamic" mode that automatically adapts to the colors of the webpage you are reading.
- **RTL Native**: Built from the ground up to perfectly render Right-To-Left languages like Arabic and Hebrew.

### 🚀 Getting Started
*Note: Because this extension uses Google's experimental Built-in AI features, you must enable them in your browser first!*

1. Open a new tab and go to: `chrome://flags/#translation-api`
2. Change the setting to **Enabled**.
3. Restart Chrome.
4. Highlight any text on any webpage, and the translation will appear instantly!

### ⚙️ Customization
Click the Settings gear inside the translation popup (or the extension icon in your toolbar) to configure your preferred Target Language, manage your Theme, and set fallback languages in case auto-detect is turned off.
